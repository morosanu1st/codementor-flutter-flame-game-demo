# Flutter + Flame Mini Game Demo

Tiny starter that shows a Flutter app hosting a Flame game loop: a bouncing ball, score, and tap-to-reset. Structure you can extend into a real 2D game.

## Layout

```
lib/
  main.dart          # Flutter entry + GameWidget
  bounce_game.dart   # Flame Game + ball component
pubspec.yaml         # flutter + flame deps
```

## Run locally

```bash
flutter create .   # if you need platform folders
flutter pub get
flutter run
```

Requires Flutter SDK 3.16+ and Flame 1.x.
